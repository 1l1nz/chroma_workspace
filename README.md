# Workspace Chroma

Легковесное расширение для VS Code, которое автоматически генерирует уникальные детерминированные цветовые акценты для каждого рабочего пространства (воркспейса).

## Как это работает
1. Вычисляет 32-битный хеш имени корневой директории воркспейса с помощью строкового алгоритма **djb2**.
2. Отображает полученное числовое значение в цветовое пространство HSL с выверенной насыщенностью и яркостью.
3. Задает значения для токенов интерфейса `statusBar`, `titleBar` и `activityBar` через VS Code Configuration API.

## Особенности
* **Нулевой оверхед:** код срабатывает один раз при загрузке воркспейса и не оставляет активных фоновых процессов в памяти.
* **Детерминированность:** для одной и той же папки всегда генерируется строго один и тот же оттенок интерфейса.
* **Чистый нативный API:** изменения вносятся напрямую в настройки рабочего пространства редактора (`workbench.colorCustomizations`).
